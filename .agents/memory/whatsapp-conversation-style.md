---
name: WhatsApp conversation style
description: Conversation continuity and response-style rules for the WhatsApp AI agent.
---

The model should own the first-message greeting and the server should send its reply unchanged; server-side greeting prefixes can duplicate a valid greeting generated by the model.

**Why:** A real context test produced the configured greeting twice when both layers tried to add it.

**How to apply:** Keep greeting, brevity, one-final-emoji, empathy, and context continuity in the agent prompt. Do not prepend a greeting in the webhook response path.
