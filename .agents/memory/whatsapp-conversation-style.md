---
name: WhatsApp conversation style
description: Conversation continuity and response-style rules for the WhatsApp AI agent.
---

The model should own the first-message greeting and the server should send its reply unchanged; server-side greeting prefixes can duplicate a valid greeting generated by the model.

**Why:** A real context test produced the configured greeting twice when both layers tried to add it.

**How to apply:** Keep greeting, brevity, one-final-emoji, empathy, and context continuity in the agent prompt. Do not prepend a greeting in the webhook response path.

Consecutive saved inbound messages received before the agent replies are one user turn and should produce one reply. Do not repeat greetings, warnings, or questions across fragments.

**Why:** The user asked that the agent understand the message burst before responding so the conversation feels natural and avoids repetitive replies.

**How to apply:** Preserve sender order, defer a reply while newer same-sender webhook events are queued, and provide the unanswered saved messages together. Do not recover provider history.

Across turns, retain details the client already provided and ask only for missing information. For a booking request, once the client selects one of the available times, reserve it without asking for another confirmation.

**Why:** The user requires continuity even when booking details arrive one message at a time and wants the scheduling flow to stay fast.

**How to apply:** Keep the booking context between turns, merge new details instead of re-asking, and treat selection from the offered available times as consent to reserve.

Never include professional names in any WhatsApp message, including offered slots, confirmations, reminders, or replies to requests for a specific professional. Keep names only for internal appointment assignment.

**Why:** the user explicitly requested that no professional names be shared with clients.

**How to apply:** Keep all client-facing WhatsApp text free of professional names and retain the name only in internal booking data.

Before replying, identify the situation, exact subject, and intent; read the full current message and relevant recent context. Answer only the actual question using confirmed facts, and ask a concise clarification when meaning is ambiguous.

**Why:** the user asked that the WhatsApp agent check each message and avoid random or context-free replies.

**How to apply:** Keep this as an explicit pre-response check in both the production prompt and any prompt that simulates the agent.

If a client gives a clear pause while checking a booking or consulting someone, acknowledge it without pressure, preserve the booking draft, and do not repeat the offered time list. If the client accepts an offer in the immediately previous message, carry out that offer instead of asking the same question again.

**Why:** The user shared real conversations where the agent repeated appointment options after the client said she would check with a friend, and where it re-asked about services after the client accepted the offer.

**How to apply:** Use the recent assistant message to interpret short replies such as “Eu quero”; answer the accepted offer directly. For a booking deferral without a new date, time, or cancellation, send a short acknowledgment and leave the saved draft intact.

For every reply, use the full available conversation and the last agent question to interpret intent; preserve all details already given, answer the current subject, and ask only one concise question when an essential detail is missing. Distinguish appointment-only advanced aesthetics and facial rituals from walk-in tanning: natural bronze until 11:30, machine bronze until 20:00 weekdays and 18:00 Saturdays. Do not assume the flow for spray/vapor bronze; use official information only and hand off health concerns or unknowns.

**Why:** The user supplied additional WhatsApp service and conversation rules and asked that all readable content be integrated.

**How to apply:** Keep these continuity, question-review, and service-flow rules in both the production agent prompt and the agent test prompt; never override confirmed catalog facts or validated booking behavior.

Before asking a follow-up, reuse a clear service or modality choice already stated by the client, even if later messages briefly cover logistics. For a broad price request, answer for the chosen bronze method instead of asking the client to choose it again; ask again only if she is comparing, changes her choice, or the history is genuinely ambiguous.

**Why:** The user reported that the agent repeated the natural-versus-machine question after the client had already chosen solar bronze earlier in the conversation.

**How to apply:** Review recent client messages, not just the current message or assistant wording, for an explicit choice. Carry that choice into price follow-ups and preserve the normal clarification flow when no choice exists.

Keep WhatsApp conversation history unified by customer phone when the Spa changes its connected Evolution number. Do not clear or partition the customer's saved conversation solely because the Spa line changed.

**Why:** The user chose to preserve a unified history across connected Spa numbers so returning clients keep continuity.

**How to apply:** Continue retrieving app-saved conversation messages by customer phone; do not introduce instance-based history isolation unless the user changes this rule.

Treat the WhatsApp interaction as consultative sales: use the full conversation to understand the client's goals and preferences, offer only relevant confirmed services without pressure, and respect declined offers. When the client broadly explores Spa services or general prices, send both the Spa/bronze menu and the advanced-aesthetics catalog proactively, each with a separate caption explaining its contents; do not ask permission first.

**Why:** The user asked for charismatic, empathetic, context-aware service that presents relevant services and clarified that catalogs should be sent naturally during discovery, not only when requested.

**How to apply:** Ground suggestions and benefits in confirmed service information, avoid repeated or unrelated upsells, and send the paired catalogs once when broad service discovery begins, explaining each PDF in its own caption. Do not send them in arrival updates, logistics, or a specific booking exchange.
